Analyse faite avant toute refonte. Lecture des 15 fichiers suivis (≈ 8 000 lignes), exécution
des moteurs en local avec Python 3.12 + SymPy 1.13.3 (= Pyodide 0.27.7), mesure des fichiers

## 1. Architecture

```
index.html            accueil — CSS et JS dans la page, ruban de Möbius animé, choix de filière
ensemble-definition/  index.html + ensemble_def.py (2 199 l.) — noyau de fait des outils d'analyse
derivee-variations/   index.html + derivee_variations.py (488 l.)
limites-asymptotes/   index.html + limites_asymptotes.py (529 l.)
etude-complete/       index.html (684 l., graphique) + etude_complete.py (168 l.)
factorisation/        index.html + factorisation.py (1 754 l.)
simplexe/             index.html seul (881 l., JS sans dépendance, fractions BigInt, canvas 2D/3D)
```

- **Python dans le navigateur** : Pyodide 0.27.7 (Python 3.12) + SymPy 1.13.3, dans un Web Worker
  créé à partir d'un Blob. **Formules** : KaTeX 0.16.11. Les deux viennent de jsDelivr.
- **Partagé** : seulement le noyau Python. Dérivée, limites et factorisation téléchargent
  `../ensemble-definition/ensemble_def.py` ; l'étude complète charge 4 fichiers de 3 dossiers.
  Les imports portent sur des noms privés (`_analyser`, `_sympy`, `_SP`, `en_sympy`…).
- **Dupliqué** dans les 5 pages Pyodide : ≈ 70 lignes de CSS et ≈ 200 lignes de JS presque
  identiques (worker, délais, aperçu, clavier, exemples, navigation par étapes, PDF, hasard,
  tableau de signes en trois variantes). Le simplexe a son propre CSS (même palette).
- **Deux identités visuelles** : accueil (Source Serif, papier, bordeaux) et outils
  (police système, bleu). Pas d'en-tête ni de pied de page commun : aucun outil ne renvoie à
  l'accueil.

### Faible / dette

- Code mort : mode « gradient » du simplexe (`AFFICHER_GRADIENT=false`, `rendreGrad`, `#ctrlGrad`),
  `ordonnerPlan` (`:300`), `derivee_variations._c`, `ensemble_def.egaux`, CSS `.tsigne` de la
  factorisation, commentaire « fourmi » (`index.html:382`), README de l'ED obsolète.
- Notation suisse : « 1'000 » refusé à la saisie ; « 1 000 » lu 1·000 = 0 ; graduations du
  graphique avec un point (`etude-complete/index.html:317`).
- Texte du moteur injecté via `innerHTML` (sûr aujourd'hui grâce aux tokeniseurs, fragile).
- Affichage lourd des coefficients fractionnaires : f' de √x écrit `\frac{\frac{1}{2}}{\sqrt{x}}`.

### Accessibilité

- Pas de retour à l'accueil depuis les outils, pas de pied de page.
- Doré de l'accueil : contraste 3,7:1 (`.eyebrow`, `.track-label`) < 4,5:1 (WCAG AA).
- Boutons ⌫, C, −, + sans `aria-label` ; `#etat`/`#apercu` sans `aria-live` ;
  tableaux de signes sans `<th>` ; canvas sans alternative ; accueil vide sans JavaScript.

- Animation Möbius en continu, même hors écran.
