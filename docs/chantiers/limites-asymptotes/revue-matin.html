8.11a — e^x/ln(x) (\(x \to +\infty\)) · nouvelle

Rédaction de l'outil

\[\displaystyle\lim_{x\to +\infty} \frac{e^{x}}{\ln(x)}\]

Étape 1 : on remplace.

Haut : \(e^{x} \to +\infty\). Bas : \(\ln(x) \to +\infty\). Forme \(\dfrac{+\infty}{+\infty}\) : indéterminée.
Prédiction avec la règle du podium

Au haut : \(e^{x}\). Au bas : \(\ln(x)\). Sur le podium, l'exponentielle bat le logarithme : c'est le haut qui gagne, donc le quotient part vers l'infini.

Signe : haut > 0, bas > 0, donc quotient > 0.

On s'attend à : \(+\infty\)

Étape 2 : BH.

haut : \(e^{x}\)\(\longrightarrow\)dérivée : \(e^{x}\)
bas : \(\ln(x)\)\(\longrightarrow\)dérivée : \(\frac{1}{x}\)
\[\lim_{x\to +\infty} \frac{e^{x}}{\ln(x)} \overset{\text{BH}}{=} \lim_{x\to +\infty} \frac{e^{x}}{\frac{1}{x}}\]

Étape 3 : on simplifie.

Diviser par \(\frac{1}{x}\), c'est multiplier par \(x\) :
\[\frac{e^{x}}{\frac{1}{x}} = e^{x}\,x = x\,e^{x}\]

Étape 4 : on remplace.

\(x \to +\infty\) et \(e^{x} \to +\infty\), donc \(x\,e^{x} \to \left(+\infty\right) \cdot \left(+\infty\right) = +\infty\).
\(\lim_{x\to +\infty} \frac{e^{x}}{\ln(x)} = +\infty\)
✓ Le calcul confirme la prédiction du podium.

Corrigé (transcription)

  • E1 [on remplace] Haut : e^x → +∞. Bas : ln(x) → +∞. Forme +∞/+∞ : indéterminée.
  • P : Au haut : e^x. Au bas : ln(x). Sur le podium, e^x bat ln(x) : c'est le haut qui gagne, donc le quotient part vers l'infini. Signe : haut > 0, bas > 0, donc quotient > 0. On s'attend à : +∞
  • E2 [BH] « On dérive le haut et le bas séparément : » T : haut : e^x → dérivée : e^x ; bas : ln(x) → dérivée : 1/x. C : lim e^x/ln x =BH lim e^x/(1/x).
  • E3 [on simplifie] « Diviser par 1/x, c'est multiplier par x : » e^x/(1/x) = e^x·x.
  • E4 [on remplace à nouveau] e^x → +∞ et x → +∞, donc x e^x → (+∞)·(+∞) = +∞ : pas indéterminée.
  • R : lim e^x/ln(x) = +∞ ; ✓.
  • (Outil : « on remplace » au lieu de « on remplace à nouveau » : écart mineur.)

Écarts : « on remplace » au lieu de « on remplace à nouveau » (étape 4).

8.11b — x^3*ln(x) (\(x \to 0^+\)) · nouvelle

Rédaction de l'outil

\[\displaystyle\lim_{x\to 0^{+}} x^{3}\,\ln(x)\]

Étape 1 : on remplace.

\(x^{3} \to \left(0^{+}\right)^{3} = 0^{+}\). \(\ln(x) \to -\infty\). Forme \(0 \cdot \left(-\infty\right)\) : indéterminée.
Prédiction avec la règle du podium

Produit : \(x^{3} \to 0^{+}\) et \(\ln(x) \to -\infty\). La puissance est plus forte que le logarithme : c'est \(x^{3}\) qui impose sa limite, donc 0.

Signe : \(x^{3}\) > 0 et \(\ln(x)\) < 0, donc produit < 0.

On s'attend à : \(0^{-}\)

Étape 2 : on transforme le produit en quotient.

BH ne marche pas sur un produit. On écrit \(x^{3} = \frac{1}{x^{-3}}\) :
\[x^{3}\,\ln(x) = \frac{\ln(x)}{x^{-3}}\]
Pourquoi garder \(\ln(x)\) en haut ? Parce que sa dérivée \(\frac{1}{x}\) est simple. Si on mettait \(\dfrac{1}{\ln(x)}\) en bas, sa dérivée serait compliquée.

Étape 3 : on vérifie la forme.

Haut : \(\ln(x) \to -\infty\). Bas : \(x^{-3} \to \left(0^{+}\right)^{-3} = +\infty\). Forme \(\dfrac{-\infty}{+\infty}\) : indéterminée.

Étape 4 : BH.

haut : \(\ln(x)\)\(\longrightarrow\)dérivée : \(\frac{1}{x}\)
bas : \(x^{-3}\)\(\longrightarrow\)dérivée : \(-3x^{-4} = -\frac{3}{x^{4}}\)
\[\lim_{x\to 0^{+}} \frac{\ln(x)}{x^{-3}} \overset{\text{BH}}{=} \lim_{x\to 0^{+}} \frac{\frac{1}{x}}{-3x^{-4}}\]

Étape 5 : on simplifie.

Diviser par une fraction, c'est multiplier par son inverse :
\[\frac{\frac{1}{x}}{-3x^{-4}} = \frac{1}{x}\,\left(-\frac{x^{4}}{3}\right) = -\frac{x^{3}}{3}\]

Étape 6 : on remplace.

\(x^{3} \to 0^{+}\) et \(\frac{-x^{3}}{3} \to \dfrac{0^{-}}{3} = 0^{-}\).
\(\lim_{x\to 0^{+}} x^{3}\,\ln(x) = 0^{-}\)
✓ Le calcul confirme la prédiction du podium.

Corrigé (transcription)

  • E1 [on remplace] x³ → (0⁺)³ = 0⁺. ln(x) → −∞ (quand x → 0⁺, le graphe de ln plonge vers le bas). Forme 0·(−∞) : indéterminée.
  • P : Produit : x³ → 0 et ln(x) → −∞. La puissance x³ est plus forte que ln(x) (le podium reste vrai en 0⁺) : c'est x³ qui impose sa limite, donc 0. Signe : pour 0 < x < 1, x³ > 0 et ln(x) < 0, donc produit < 0. On s'attend à : 0⁻
  • E2 [on transforme le produit en quotient] BH ne marche pas sur un produit. On écrit x³ = 1/x⁻³ : x³ ln(x) = ln(x)/x⁻³. Remarque : « Pourquoi garder ln(x) en haut ? Parce que sa dérivée 1/x est simple. Si on mettait 1/ln(x) en bas, sa dérivée serait compliquée. »
  • E3 [on vérifie la forme] Haut : ln(x) → −∞. Bas : x⁻³ = 1/x³ → 1/0⁺ = +∞. Forme −∞/+∞ : indéterminée, on peut utiliser BH.
  • E4 [BH] T : haut : ln(x) → dérivée : 1/x ; bas : x⁻³ → dérivée : −3x⁻⁴ = −3/x⁴. C : lim ln(x)/x⁻³ =BH lim (1/x)/(−3/x⁴).
  • E5 [on simplifie] (diviser par une fraction = multiplier par son inverse) : (1/x)/(−3/x⁴) = (1/x)·(−x⁴/3) = −x⁴/(3x) = −x³/3.
  • E6 [on remplace] x³ → 0⁺, donc −x³/3 → 0⁻ : pas indéterminée.
  • R : lim x³ ln(x) = 0⁻ ; ✓.

8.14 — ln(1+e^x)/e^x (\(x \to -\infty\)) · nouvelle

Rédaction de l'outil

\[\displaystyle\lim_{x\to -\infty} \frac{\ln\left(1 + e^{x}\right)}{e^{x}}\]

Étape 1 : on remplace.

Haut : \(1 + e^{x} \to 1\text{, donc }\ln\left(1 + e^{x}\right) \to 0^{+}\). Bas : \(e^{x} \to e^{-\infty} = 0^{+}\). Forme \(\dfrac{0^{+}}{0^{+}}\) : indéterminée.
Prédiction avec la règle du podium

Ici, le podium ne peut pas aider : il n'y a pas de « course » entre une exponentielle, une puissance et un logarithme qui partent vers l'infini.

Pour prédire, on utilise la calculatrice (tableau ci-dessous).

\(x\)\(-1\)\(-10\)\(-20\)\(-25\)\(-30\)
\(\frac{\ln\left(1 + e^{x}\right)}{e^{x}}\)\(0{,}8515\)\(0{,}99998\)\(\approx 1\)\(\approx 1\)\(\approx 1\)
La calculatrice ne prouve rien : c'est le calcul qui suit qui donne la réponse sûre.

Étape 2 : BH.

Pour dériver \(\ln\left(1 + e^{x}\right)\), on utilise \(\left(\ln u\right)' = \dfrac{u'}{u}\) avec \(u = 1 + e^{x}\) et \(u' = e^{x}\).
haut : \(\ln\left(1 + e^{x}\right)\)\(\longrightarrow\)dérivée : \(\frac{e^{x}}{1 + e^{x}}\)
bas : \(e^{x}\)\(\longrightarrow\)dérivée : \(e^{x}\)
\[\lim_{x\to -\infty} \frac{\ln\left(1 + e^{x}\right)}{e^{x}} \overset{\text{BH}}{=} \lim_{x\to -\infty} \frac{\frac{e^{x}}{1 + e^{x}}}{e^{x}}\]

Étape 3 : on simplifie.

Diviser par une fraction, c'est multiplier par son inverse :
\[\frac{\frac{e^{x}}{1 + e^{x}}}{e^{x}} = \frac{e^{x}}{1 + e^{x}}\,\frac{1}{e^{x}} = \frac{1}{1 + e^{x}}\]

Étape 4 : on remplace.

\(1 + e^{x} \to 1\) et \(\frac{1}{1 + e^{x}} \to \dfrac{1}{1} = 1\).
\(\lim_{x\to -\infty} \frac{\ln\left(1 + e^{x}\right)}{e^{x}} = 1\)
La calculatrice avait bien « deviné » : le calcul le confirme.
