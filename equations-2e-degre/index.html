Équations du 2e degré

Écrivez une équation du 2e degré (inconnue x ou une autre lettre) : elle est résolue avec les méthodes du cours, dans leur ordre, étape par étape.

Aperçu de l'équation
Chargement de Python…
Saisie : x^2-5x-36=0, 4x^2+2x=56, (x+1)(x+3)=15, 4(x-2)^2=1. Autre lettre que x acceptée (t^2+20t+100=0). Fractions et décimaux : t^2+t+1/4=0, 0,5x^2-2=0.
Rappel de la méthode

Pour factoriser, on procède dans l'ordre :

  1. Mise en évidence (ME).
  2. Identité remarquable (Id. rem.) : \(A^2-B^2=(A+B)(A-B)\), \(A^2+2AB+B^2=(A+B)^2\), \(A^2-2AB+B^2=(A-B)^2\).
  3. Somme-Produit (S-P), si le trinôme est unitaire (\(a=1\)) : \(x^2+bx+c=(x+p)(x+q)\), où \(p\cdot q=c\) et \(p+q=b\).
  4. Tâtonnement, si \(a\neq1\) : on cherche une solution entière \(r\) parmi les diviseurs de \(c\) ; alors \(ax^2+bx+c=(x-r)(ax+\triangle)\), avec \((-r)\cdot\triangle=c\).
  5. La formule : \(\Delta=b^2-4ac\) ; si \(\Delta>0\), \(x_{1,2}=\dfrac{-b\pm\sqrt{\Delta}}{2a}\) ; si \(\Delta=0\), \(x=\dfrac{-b}{2a}\) ; si \(\Delta<0\), \(S=\varnothing\).

Puis : un produit est nul si et seulement si l'un des facteurs est nul.
