Aperçu de l'équation
Chargement de Python…
Saisie : 3^(x+1)=27, 2^x=100, 37*e^(-0,02t)=25. log est le logarithme de base 10, ln celui de base e, log_2(x) celui de base 2 ; e est toujours le nombre e. Pour calculer un logarithme, écrivez-le sans « = » : log_2(50), log_8(64).
Rappel de la méthode

Selon la forme de l'équation :

  1. Équation exponentielle : deux méthodes, au choix avec les boutons placés au-dessus du corrigé.
    • Même base / définition : on écrit les deux membres avec la même base, puis \(a^A=a^B\iff A=B\). Exemple : \(4^x=8\iff 2^{2x}=2^3\iff 2x=3\). Pour une base 10 ou e : \(10^x=b\iff x=\log(b)\) et \(e^x=b\iff x=\ln(b)\). Sinon, le corrigé dit qu'il faut les logarithmes.
    • Logarithmes (toujours possible) : on isole l'exponentielle, on prend le logarithme des deux membres (\(\ln\) dès qu'une base est \(e\)), puis \(\log(a^A)=A\log(a)\) ; on remplace \(\log(10)\) et \(\ln(e)\) par 1 ; on divise par \(\log(a)\). Exemple : \(10^x=8\iff x\log(10)=\log(8)\iff x=\log(8)\). Si le second membre est négatif ou nul, il n'y a aucune solution : une exponentielle est strictement positive.
    • Bases différentes : \(a^f=b^h\) : logarithme des deux membres, on développe, on met \(x\) en facteur, puis on divise.
  2. Équation logarithmique : on applique l'exponentielle aux deux membres, \(\log_a(u)=c\iff a^{\log_a(u)}=a^c\), puis \(a^{\log_a(A)}=A\) (pour \(A>0\)) : \(u=a^c\). On vérifie ensuite que l'argument est strictement positif. Si la base est l'inconnue : \(x>0\) et \(x\neq1\). Plusieurs logarithmes imbriqués : on recommence pour chacun.
  3. Calculer \(\log_a(y)\) : si \(y=a^k\), alors \(\log_a(y)=k\) ; sinon \(\log_a(y)=\dfrac{\log(y)}{\log(a)}\) (changement de base).

Propriétés utiles : \(\log(a^A)=A\log(a)\), \(\log(10)=1\), \(\ln(e)=1\), \(\log(a)-\log(b)=\log\left(\dfrac ab\right)\), \(\log(a)+\log(b)=\log(ab)\). Quand une solution est un nombre simple écrit avec des logarithmes, vérifiez-la à la calculatrice.
