Aperçu de l'équation
Chargement de Python…
Saisie : 3^(x+1)=27, 2^x=100, 37*e^(-0,02t)=25. log est le logarithme de base 10, ln celui de base e, log_2(x) celui de base 2 ; e est toujours le nombre e. Pour calculer un logarithme, écrivez-le sans « = » : log_2(50), log_8(64).
Rappel de la méthode

Selon la forme de l'équation :

  1. Même base : on écrit les deux membres avec la même base, puis \(a^A=a^B\iff A=B\). Exemple : \(4^x=8\iff 2^{2x}=2^3\iff 2x=3\).
  2. Logarithme : on isole l'exponentielle, puis \(10^x=b\iff x=\log(b)\) et \(e^x=b\iff x=\ln(b)\) ; pour une autre base, on prend le logarithme des deux membres : \(a^x=b\iff x\log(a)=\log(b)\). Si \(b\le0\), il n'y a aucune solution : une exponentielle est strictement positive.
  3. Bases différentes : \(a^f=b^h\) : logarithme des deux membres, on développe, on met \(x\) en facteur, puis on divise.
  4. Équation logarithmique : \(\log_a(u)=c\iff u=a^c\) (définition du logarithme), puis on vérifie que l'argument est strictement positif. Si la base est l'inconnue : \(x>0\) et \(x\neq1\).
  5. Calculer \(\log_a(y)\) : si \(y=a^k\), alors \(\log_a(y)=k\) ; sinon \(\log_a(y)=\dfrac{\log(y)}{\log(a)}\) (changement de base).

Propriétés utiles : \(\log(10^k)=k\), \(\ln(e^k)=k\), \(\log(a^A)=A\log(a)\), \(\log(a)-\log(b)=\log\left(\dfrac ab\right)\), \(\log(a)+\log(b)=\log(ab)\).
